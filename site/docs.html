Installing

Download the APK from the download section or from the Releases page. Each release contains one APK per app and a SHA256SUMS file. To verify a download, put both files in one folder and run:

sha256sum -c SHA256SUMS

The apps need Android 8.0 or newer. They are separate applications with separate data, packages and settings.

First start

The first start downloads the base system (bash, coreutils, apt and friends) from the TP releases, verifies its SHA-256 checksum and unpacks it into the app's private storage. A progress screen shows the steps. This happens once per app.

If the download fails, the screen offers Retry and Use system shell. The second option opens Android's own shell so the app stays usable, but without bash and apt.

The menu entry Reinstall bootstrap deletes everything under $PREFIX, including packages you installed, and downloads a fresh copy. Your home folder is kept.

Sessions and the menu

Sessions are tabs at the top. Tap a tab to switch, tap + for a new session and ⋮ for the menu. A foreground notification keeps sessions alive when you leave the app; its Exit button closes everything.

Long-press a tab for Rename and Close (plus the split entries described below). When a process ends, the session prints a message and closes when you press Enter.

Split sessions

Up to four sessions can be shown side by side.

  1. Long-press the tab of session 2 and choose Combine with....
  2. Pick session 1. Session 1 becomes the owner on the left and session 2 appears on the right.
  3. Repeat with sessions 3 and 4 to add them to the same group.

Two sessions are shown left and right. With three, the owner takes the whole left side and the other two are stacked on the right. With four, the screen is a 2×2 grid. The pane you touched last has a blue border and receives all input, extra keys and pastes. Tabs of one group share a coloured underline.

To split a group again, long-press the owner's tab and choose Eject all sessions. Long-press a member's tab and choose Eject from group to remove only that one. Closing the owner dissolves the group; closing a member only removes it from the group.

Selecting and copying

Long-press a word to select it, then drag the blue handles to extend the selection. The screen scrolls when you drag to the top or bottom edge. The bar above the terminal offers Copy, Select all and Cancel.

Copy stores the text in the Term clipboard (a history of the last 10 copies), not in Android's clipboard. Programs can also fill it themselves with the OSC 52 escape sequence, which tmux and neovim use.

Term clipboard keyboard

The Term clipboard keyboard types everything you copied into any other app.

  1. Open the menu and choose Enable Term clipboard keyboard, then switch on the keyboard named after your app (for example TermOne Clipboard).
  2. In the other app, open a text field and switch keyboards with Switch keyboard or Android's keyboard button.
  3. Pick an entry from the chips, then press Insert all.

Long texts are inserted in chunks with a progress percentage. The keyboard also has Space, Backspace, Enter, Delete (removes the chosen entry) and Clear (removes all entries).

Extra keys

The bar under the terminal has two rows. Swipe it to the left for the VNC row; the dots show the current page. A hardware keyboard works as well.

  • CTRL, ALT, SHIFT and FN: tap once to apply to the next key only (blue), tap twice quickly to lock (amber), tap again to release.
  • With FN: arrows become PageUp, PageDown, Home and End; the digits 1 to 0 send F1 to F10.
  • Arrow, PageUp and PageDown keys repeat while you hold them.

Layout file

The layout is ~/.term/extrakeys.properties. Each line is a comma-separated list of keys:

row1=ESC,TAB,CTRL,ALT,SHIFT,UP,DOWN,HOME,END
row2=LEFT,RIGHT,PGUP,PGDN,-,/,|,~,FN
vnc-row=VNC_LEFT_CLICK,VNC_RIGHT_CLICK,VNC_MIDDLE_CLICK,VNC_SCROLL_UP,VNC_SCROLL_DOWN,VNC_KEYBOARD,VNC_FIT,VNC_CLOSE
KeysNames
ModifiersCTRL, ALT, SHIFT, FN
NavigationESC, TAB, UP, DOWN, LEFT, RIGHT, HOME, END, PGUP, PGDN, INS, DEL, BKSP, ENTER
Function keysF1 to F12
ActionsKEYBOARD (show or hide the keyboard), PASTE (paste the system clipboard), COMMA (a comma)
VNCVNC_LEFT_CLICK, VNC_RIGHT_CLICK, VNC_MIDDLE_CLICK, VNC_SCROLL_UP, VNC_SCROLL_DOWN, VNC_KEYBOARD, VNC_FIT, VNC_CLOSE
Anything elseTyped literally, for example -, / or |.

The vnc-row is split into two rows. Use Reload config in the menu after editing.

Inline images

The terminal draws sixel graphics and iTerm2 inline images. It answers the terminal queries that image tools use for detection, so most of them work without configuration.

Any program that writes sixel to the terminal works. To show a file with the iTerm2 protocol from plain bash:

printf '\033]1337;File=inline=1;width=auto:%s\a' "$(base64 -w0 image.png)"

The width and height options accept cells, pixels (200px), percentages (50%) and auto. Images scroll with the text and disappear when text is written over them.

VNC

The viewer is built in. It supports servers with no security or with VNC password authentication (passwords are limited to 8 characters by the protocol).

terminal-vnc                      # start a server on display :1 and open the viewer
terminal-vnc start -d 2 -g 1920x1080
terminal-vnc open -H 192.168.1.10 -p 5901
terminal-vnc status
terminal-vnc stop

start needs a package that provides vncserver and vncpasswd (for example TigerVNC). open works with any VNC server you can reach. Connections to other hosts than the device itself ask for confirmation first.

GestureAction

While the viewer is shown, the extra keys switch to the VNC row (LMB, RMB, MMB, scroll, keyboard, Fit, Close) and typing goes to the remote desktop. Fit toggles between fitting the screen and actual size. Back, another tab or a new session hides the viewer without disconnecting; terminal-vnc open or the menu brings it back. Text copied on the remote side lands in the Term clipboard.

Font

Put a monospaced TrueType font at ~/.term/term.ttf. Without it the system monospace font is used.

You can also use apt directly; tn simply adds repository management and the community switch below.

Repositories

Every app is configured with the main repository (TP):

deb https://term-org.github.io/TP/<applicationId> stable main

The community repository (TCP) is off by default because its recipes come from third parties. Switch it on with:

tn community enable
tn update

tn community enable explains the risk, asks for confirmation (use -y to skip it), downloads the signing key and adds the repository. tn community disable and tn community status do what they say.

Other repositories

tn repo list
tn repo add NAME URL [SUITE [COMPONENT]] [--keyring FILE]
tn repo remove NAME
tn repo enable NAME
tn repo disable NAME

Repository URLs must use https. Suite and component default to stable and main. With --keyring the key is stored and used only for that repository.

Browse the packages on the packages page.

File layout

Everything lives in the app's private internal storage, in the files folder of /data/data/<applicationId>:

VariablePath
$PREFIX/data/data/<applicationId>/files/rootdir/usr
$HOME/data/data/<applicationId>/files/rootdir/home
$TMPDIR/data/data/<applicationId>/files/temp
$DOCS/data/data/<applicationId>/files/docs

The folder is not a real root file system. Uninstalling the app or clearing its data removes all of it.

Troubleshooting

  • "Setup failed: Unable to fetch ... (HTTP 404)": no bootstrap has been published for your app and architecture yet. Retry later or use the system shell.
  • "Checksum mismatch": the download was corrupted or changed. Press Retry; the archive is never unpacked when the checksum is wrong.
  • tn update finds nothing: run tn doctor to see whether a repository is configured and the tools are present.
  • VNC does not open: make sure a server is listening on the port, for example with terminal-vnc status.
