Installing

Download the APK from the download section or from the Releases page. Each release contains one APK per app and a SHA256SUMS file. To verify a download, put both files in one folder and run:

sha256sum -c SHA256SUMS

The apps need Android 8.0 or newer. They are separate applications with separate data, packages and settings.

First start

The first start downloads the base system (bash, coreutils, apt and friends) from the TP releases, verifies its SHA-256 checksum and unpacks it into the app's private storage. A progress screen shows the steps. This happens once per app.

If the download fails, the screen offers Retry and Use system shell. The second option opens Android's own shell so the app stays usable, but without bash and apt.

The menu entry Reinstall bootstrap deletes everything under $PREFIX, including packages you installed, and downloads a fresh copy. Your home folder is kept.

Sessions and the menu

Sessions are tabs at the top. Tap a tab to switch, tap + for a new session and ⋮ for the menu. A foreground notification keeps sessions alive when you leave the app. Its buttons are Wake lock and Exit.

Long-press a tab for Rename and Close (plus the split entries described below).

Typing exit or pressing Ctrl+D closes the session immediately, without pressing Enter, and stops every process that was started from it, including daemons that detached from the shell. When the last session closes, the app closes too. The only exception is a shell that fails to start; then the error stays on the screen so you can read it.

Split sessions

Up to four sessions can be shown side by side.

  1. Long-press the tab of session 2 and choose Combine with....
  2. Pick session 1. Session 1 becomes the owner on the left and session 2 appears on the right.
  3. Repeat with sessions 3 and 4 to add them to the same group.

Two sessions are shown left and right. With three, the owner takes the whole left side and the other two are stacked on the right. With four, the screen is a 2×2 grid. The pane you touched last has a blue border and receives all input, extra keys and pastes. Tabs of one group share a coloured underline.

Resizing the panes

Drag the line between two panes. A small handle marks it. While you drag, only a preview line moves; the terminals change size when you lift your finger. In the 2×2 grid, dragging the crossing point moves both lines. Panes always keep between 20% and 80% of the space.

Maximizing a pane

Open the menu and choose Maximize pane to show only the active pane at full size. The other panes keep running. Switching to another tab of the group shows that session instead. Choose Restore panes to bring the split back.

Splitting a group again

Long-press the owner's tab and choose Eject all sessions. Long-press a member's tab and choose Eject from group to remove only that one. Closing the owner dissolves the group; closing a member only removes it from the group.

Selecting and copying

Long-press a word to select it, then drag the blue handles to extend the selection. The screen scrolls when you drag to the top or bottom edge. While a selection exists, the bar that replaces the tabs offers Copy, Select all and Cancel, so nothing covers the text.

Copy stores the text in the Term clipboard (a history of the last 10 copies), not in Android's clipboard. Programs can also fill it themselves with the OSC 52 escape sequence, which tmux and neovim use.

Term clipboard keyboard

The Term clipboard keyboard types everything you copied into any other app.

  1. Open the menu and choose Enable Term clipboard keyboard, then switch on the keyboard named after your app (for example TermOne Clipboard).
  2. In the other app, open a text field and switch keyboards with Switch keyboard or Android's keyboard button.
  3. Pick an entry from the chips, then press Insert all.

Long texts are inserted in chunks with a progress percentage. The keyboard also has Space, Backspace, Enter, Delete (removes the chosen entry) and Clear (removes all entries).

From the shell, term-clip reads and writes the same history, see Android integration.

Links

Tap a link in the terminal. Two kinds are recognised: hyperlinks that programs write with the OSC 8 escape sequence (they are underlined), and plain http:// and https:// addresses found in the text, even when the line was wrapped. A dialog shows the real address with Open, Copy and Cancel. The confirmation is always shown, because a hyperlink can display one text and lead somewhere else.

Links with the schemes http, https, mailto, tel and geo are accepted; anything else is ignored. Copy puts the address in the Term clipboard. While a program uses the mouse (for example vim with mouse support), taps go to that program instead.

To try it:

printf '\033]8;;https://github.com/Term-org\033\\Term-org\033]8;;\033\\\n'

Searching the scrollback

Choose Search scrollback in the menu. A search bar replaces the tabs. Type to find text: matches are highlighted in the terminal, the current one in a brighter colour, and the counter shows the position, for example 3/12. Use ▲ and ▼ (or Enter) to move between matches and ✕ (or Back) to close the bar.

The search ignores letter case, starts at the newest match and covers the scrollback and the screen of the active pane. A match cannot span two wrapped lines.

Zoom and volume keys

Pinch with two fingers to change the font size of all panes (8 to 40). Reload config returns to the size in term.properties.

The volume keys work as modifiers while you hold them: volume down is Ctrl and volume up is Alt. Hold volume down and press c for Ctrl+C. The extra keys light up in blue while a volume key is held. Set volume-keys=false in term.properties to get the normal volume control back.

Extra keys

The bar under the terminal has two rows. Swipe it to the left for the VNC row; the dots show the current page. A hardware keyboard works as well.

  • CTRL, ALT, SHIFT and FN: tap once to apply to the next key only (blue), tap twice quickly to lock (amber), tap again to release.
  • With FN: arrows become PageUp, PageDown, Home and End; the digits 1 to 0 send F1 to F10.
  • Arrow, PageUp and PageDown keys repeat while you hold them.

Inline images

The terminal draws sixel graphics and iTerm2 inline images. It answers the terminal queries that image tools use for detection, so most of them work without configuration.

Any program that writes sixel to the terminal works. To show a file with the iTerm2 protocol from plain bash:

printf '\033]1337;File=inline=1;width=auto:%s\a' "$(base64 -w0 image.png)"

The width and height options accept cells, pixels (200px), percentages (50%) and auto. Images scroll with the text and disappear when text is written over them.

VNC

The viewer is built in. It supports servers with no security or with VNC password authentication (passwords are limited to 8 characters by the protocol).

terminal-vnc                      # start a server on display :1 and open the viewer
terminal-vnc start -d 2 -g 1920x1080
terminal-vnc open -H 192.168.1.10 -p 5901
terminal-vnc status
terminal-vnc stop

start needs a package that provides vncserver and vncpasswd (for example TigerVNC). open works with any VNC server you can reach. Connections to other hosts than the device itself ask for confirmation first.

While the viewer is shown, the extra keys switch to the VNC row (LMB, RMB, MMB, scroll, keyboard, Fit, Close) and typing goes to the remote desktop. Fit toggles between fitting the screen and actual size. Back, another tab or a new session hides the viewer without disconnecting; terminal-vnc open or the menu brings it back. Text copied on the remote side lands in the Term clipboard.

Android integration

These commands talk to the app through escape sequences, so they also work over SSH or inside tmux only when the sequences get through (tmux needs allow-passthrough).

CommandWhat it does
term-storageAsks for the storage permission and links the shared folders into ~/storage (shared, downloads, dcim, pictures, music, movies and external-N for removable storage).
term-open TARGETOpens a link or a file with another app. Add -t MIME to force the type. The app asks for confirmation first.
term-share [FILE]Shares a file, or the text from the standard input, with another app. Asks for confirmation first.
term-notifyShows a notification: term-notify -t Build "Finished". Options -i ID (replaces an earlier notification), --ongoing and --remove.
term-clipReads and writes the Term clipboard: set, get [N], list and clear. Works in pipes: git diff | term-clip set.
term-wakelock on|offKeeps the CPU and Wi-Fi awake while the screen is off. The notification shows the state and has a button for it. It is released when the last session closes.
term-themeLists and applies color themes, see Color themes.

term-open and term-share only accept files inside the app storage or the shared storage, and links with the schemes http, https, mailto, tel and geo. A program that prints the right escape sequence cannot open or share anything without you confirming it.

The Files app

Each app appears in Android's Files app (and in every other app that uses the system file picker) as a storage location, next to the other apps. It shows your home folder, and you can browse, open, create, rename and delete files there.

Color themes

Colors are read from ~/.term/colors.properties. Without that file the default colors are used. Changes apply to every session right away.

term-theme list           # available themes
term-theme show dracula   # preview
term-theme set dracula    # apply
term-theme current
term-theme reset          # back to the defaults

Built-in themes: default, dracula, nord, solarized-dark, solarized-light, gruvbox-dark, one-dark and tokyo-night. Your own themes go in ~/.term/themes/NAME.properties and show up in the list marked custom.

A theme is a list of colors as #RRGGBB. Every key is optional:

foreground=#C0CAF5
background=#1A1B26
cursor=#C0CAF5
color0=#15161E
color1=#F7768E
# ... up to color15

Commands from other apps

Other apps can run commands in the terminal through RunCommandService. It is off by default and needs two things:

  1. Set allow-external-apps=true in ~/.term/term.properties.
  2. The calling app declares the permission <applicationId>.permission.RUN_COMMAND and you grant it in Android's app settings.

The caller starts the service <applicationId>/app.term.one.RunCommandService with startForegroundService() and these extras:

ExtraMeaning
RUN_COMMAND_PATHAbsolute path of the program. It must be inside the prefix or the home folder.
RUN_COMMAND_ARGUMENTSString array of arguments (at most 256).
RUN_COMMAND_WORKDIRWorking directory (default: the home folder).
RUN_COMMAND_BACKGROUNDtrue (default) runs without a session and returns the output; false opens a visible session.
RUN_COMMAND_TIMEOUT_SECONDS1 to 3600 (default 300), background mode only.
RUN_COMMAND_RESULT_PENDING_INTENTOptional. Receives a bundle named RESULT with stdout, stderr, exitCode and errmsg.

Font

Put a monospaced TrueType font at ~/.term/term.ttf. Without it the system monospace font is used. Use a Nerd Font to get the icons that tn shows; without term.ttf, tn falls back to plain text.

Shell configuration

The app writes its own shell configuration to the system folder (see File layout) on every start, and bash loads it first. It sets a short prompt (~$ in your home folder, the folder name elsewhere), history and a few aliases, and at the end it loads ~/.bash_profile and ~/.bashrc. Both of your files are empty and belong entirely to you.

The tn package manager

tn is a front end for apt and dpkg. Run tn without arguments for the interface, or use package:action on the command line.

CommandWhat it does
tn git:installInstall a package
tn "git;vim:install"Install several packages
tn git:removeUninstall a package
tn git:purgeUninstall and delete its configuration
tn git:detailsShow the details of a package
tn git:upgradeUpgrade one package
tn gp:upgradeRefresh the lists and upgrade every package (gp means global packages)
tn git:freeze / tn git:unfreezeFreeze a package so it cannot be used, and thaw it again
tn git:filesList the files of a package
tn editor:searchSearch packages
tn gp:updateRefresh the package lists
tn gp:listList installed packages
tn gp:cleanDelete downloaded package files
tn gp:autoremoveRemove packages that are no longer needed
tn doctorCheck the environment
tn -y ...Do not ask for confirmation

Names can be separated with ; or ,. The shell treats an unquoted ; as the end of the command, so write tn "a;b:install" or use tn a,b:install or tn a b:install.

Freezing

Freezing removes the execute permission from the programs of a package and puts the package on hold, so upgrades do not undo it. The libraries stay readable, so other packages that depend on them keep working. unfreeze restores everything. A frozen package cannot be removed until you unfreeze it, and the packages the system needs (bash, apt, dpkg, coreutils and a few more) cannot be frozen.

The tn interface

Run tn to open it. The package list is on the left. The right side shows the selected package in four tabs: Details, Source (which repository provides it), Readme (installed packages only) and Versions. Icons mark installed, upgradable and frozen packages.

Repositories

Every repository has a label. The main repository (TP, label tp) is configured in every app and is always active:

deb https://term-org.github.io/TP/<applicationId> stable main

The community repository (TCP, label tcp) is off by default because its recipes come from third parties. Turn it on with:

tn tcp:activate
tn gp:update

It explains the risk, asks for confirmation (-y skips it), downloads the signing key and adds the repository.

Other repositories

tn -c add https://example.com/repo -l mine -k https://example.com/key.gpg
tn -c list
tn mine:non-active
tn mine:activate
tn -c remove mine

-c can also be written community and -l as -label. A repository that you add is active right away; label:non-active and label:activate switch it off and on. The link must use https. tn checks that the repository exists, then:

  • if it is signed, you must give its public key with -k (a link or a file);
  • if it is not signed, you are warned and asked for confirmation before it is added without verification.

Optional flags: -s for the suite (default stable), -m for the component (default main) and -y. The labels tp, tcp and gp are reserved. Browse the packages on the packages page.

File layout

Everything lives in the app's private internal storage, in the files folder of /data/data/<applicationId>:

Variable or folderPath
$PREFIX/data/data/<applicationId>/files/rootdir/usr
$HOME/data/data/<applicationId>/files/rootdir/home
$TERM_SYSTEM_DIR/data/data/<applicationId>/files/rootdir/system (shell configuration and built-in themes, rewritten on every start)
$TMPDIR/data/data/<applicationId>/files/temp
$DOCS/data/data/<applicationId>/files/docs

The folder is not a real root file system. Uninstalling the app or clearing its data removes all of it.

Troubleshooting

  • "Setup failed: Unable to fetch ... (HTTP 404)": no bootstrap has been published for your app and architecture yet. Retry later or use the system shell.
  • "Checksum mismatch": the download was corrupted or changed. Press Retry; the archive is never unpacked when the checksum is wrong.
  • tn finds no packages: run tn gp:update first, then tn doctor to see whether a repository is active and the tools are present.
  • Boxes instead of icons in tn: the font has no icon glyphs. Put a Nerd Font at ~/.term/term.ttf, or run TN_ASCII=1 tn for plain text.
  • VNC does not open: make sure a server is listening on the port, for example with terminal-vnc status.
  • A command from another app is refused: check allow-external-apps=true and the RUN_COMMAND permission.
