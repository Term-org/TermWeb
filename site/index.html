A terminal for Android, built from scratch.

Four independent apps (TermOne, TermTwo, TermThree and TermFour) with session tabs, split sessions, inline images, a built-in VNC viewer and its own package manager.

Install

  1. Download the APK of the app you want. It needs Android 8.0 or newer on a 64-bit ARM or x86_64 device.
  2. Open the file and allow installing from this source when Android asks.
  3. Start the app. The first start downloads the base system (bash, coreutils, apt) once, so you need an internet connection.

The apps are not on Google Play. They target Android API 28 on purpose, because newer targets are not allowed to run programs from the app's own storage, and a terminal needs that.

Features

Session tabs

Sessions sit in a bar above the terminal, so switching is one tap.

Split sessions

Combine up to four sessions side by side and eject them again with a long press.

Inline images

Sixel and iTerm2 (OSC 1337) images are drawn right in the terminal.

Built-in VNC

Run terminal-vnc and a viewer opens inside the app, with its own row of keys.

Term clipboard

Select long text, copy it, then insert all of it into any other app with the Term clipboard keyboard.

Extra keys

Two rows of keys, plus a VNC row one swipe to the left. The layout is a plain text file.

Own package manager

tn wraps apt and manages repositories, including the community repository.

Private storage

Everything lives in the app's private internal storage. Nothing needs root.

The projects

  • TermApp: the source of TermOne to TermFour.
  • TP (Term Packages): build system, bootstrap archives and the main apt repository.
  • TCP (Term Community Packages): packages contributed by the community.
  • TermWeb: this website.
